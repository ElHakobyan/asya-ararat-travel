# Asya Ararat — установка WordPress

Это отдельная устанавливаемая тема с дизайном существующего сайта. Статический
сайт и его домен этой папкой не переключаются. Supabase теме не требуется.

## Установка на тестовый WordPress

1. Получите доступ к хостингу с WordPress (PHP + база MySQL/MariaDB).
2. Если сайт на нём уже работает — сначала сделайте резервную копию файлов и базы,
   затем создайте тестовую копию. Не активируйте тему вслепую на рабочем сайте.
3. Соберите архив: `python wordpress/package.py` из корня репозитория.
4. В WordPress: **Внешний вид → Темы → Добавить тему → Загрузить тему**.
   Выберите `wordpress/asya-ararat.zip`. На тестовой копии активируйте тему.
5. **Внешний вид → Настроить → Asya Ararat — содержимое**:
   измените тексты RU/EN/HY, телефон, логотип, главное фото, фото о компании и
   четыре фотографии галереи. Нажмите «Опубликовать».
6. **Туры → Добавить тур**: название и описание — русский вариант;
   в блоке «Цена, даты и переводы» заполните поля и EN/HY. Справа задайте
   изображение записи. Сохраните черновик или нажмите «Опубликовать».
   Поле «Порядок» управляет расположением карточки. Перевод без названия
   использует русский текст. Цена пустая означает отсутствие цены на карточке.
7. **Настройки → Постоянные ссылки → Сохранить изменения**.
8. Проверьте мобильное меню, три языка, все фото, новый тур и его скрытие
   (перевод в черновик), галерею, отправку заявки в мессенджеры и смену телефона.
9. Только после проверки подключайте домен и перенаправления. Сохраните почтовые
   DNS-записи. Тестовый сайт закройте от индексации; рабочий — по решению владельца.

## Что сохраняется

Тексты и фото настроек — в базе WordPress, туры — записи `asya_tour`, загрузки —
в медиатеке. Делайте резервные копии базы и `wp-content/uploads`. При смене темы
записи остаются в базе, но для их редактирования потребуется регистрация типа
`asya_tour` в новой теме или отдельном плагине. Настройки темы привязаны к ней.

## Границы первой версии

- Сохраняется структура готовой одностраничной витрины. Можно менять содержимое;
  произвольная перестановка блоков через Gutenberg не реализована.
- Новые туры добавляются через WordPress; старый контент asyaararat.com автоматически
  не импортируется. Существующие иллюстративные темы — в исходном HTML репозитория.
- Смена языка сохраняется в браузере; отдельные индексируемые URL языков не сделаны.
- Заявки и оценки отправляются в мессенджер. База отзывов, AI-чат и панель заявок
  Supabase в эту тему не подключены. Они остаются в исходной статической версии.
- Фото галереи по умолчанию загружаются из прежних внешних ссылок. Замените их
  собственными изображениями через настройки.
- PHP/WordPress в среде подготовки отсутствует: полноценная активация, сохранение
  в базе и внешний вид требуют проверки на тестовой установке. JS и структура
  проверены отдельно. Не считать тему уже установленной или проверенной в продакшене.
